# Pixi Skia Test

Данный проект представляет собой реализацию тестового задания по интеграции PixiJS и Skia (CanvasKit). Сделан на базе **PixiJS**, **TypeScript** и **Vite**.

## Требования

- Node.js 18+
- npm 9+

## Установка зависимостей

```bash
npm install
```

## Запуск проекта

Для запуска локального сервера разработки выполните:

```bash
npm run dev
```

По умолчанию приложение будет доступно по адресу:

```text
http://localhost:5173
```

## Сборка проекта

Для создания production-сборки:

```bash
npm run build
```

Особенности сборки:

- При локальной разработке (`vite serve`) используется базовый путь:

```text
/
```

- При production-сборке используется базовый путь:

```text
/ pixi-skia-renderer /
```

Это необходимо для корректной публикации проекта через GitHub Pages.

Собранные файлы помещаются в каталог:

```text
docs/
```

Директория `docs` используется в качестве источника публикации для GitHub Pages.

## Скрипты

| Команда         | Описание                                 |
| --------------- | ---------------------------------------- |
| `npm run dev`   | Запуск локального сервера разработки     |
| `npm run build` | Production-сборка проекта в папку `docs` |
